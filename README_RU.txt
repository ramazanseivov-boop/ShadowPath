SHADOW PATH — Android project
This is an Android Studio project source, not a precompiled APK.
Build APK:
1. Install Android Studio on a computer.
2. Open this ShadowPath folder as a project.
3. Allow Gradle sync and install Android SDK Platform 35 if prompted.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
The APK appears under app/build/outputs/apk/debug/app-debug.apk.
Game is embedded locally and works offline. It includes four fighter classes and special abilities.
